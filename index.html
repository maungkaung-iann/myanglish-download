Installation Guide

Myanglish Install ပြုလုပ်နည်း

MyanglishInstaller.exe ကို Download လုပ်ပြီး အောက်ပါအဆင့်တွေအတိုင်း တပ်ဆင်နိုင်ပါတယ်။

1
Download

Download for Windows ကိုနှိပ်ပြီး MyanglishInstaller.exe ကို Download လုပ်ပါ။

2
Run MyanglishInstaller.exe

Download လုပ်ထားတဲ့ MyanglishInstaller.exe ကို double-click လုပ်ပါ။ Administrator permission မေးလာရင် Yes ကိုနှိပ်ပါ။

3
More info

Windows SmartScreen ပေါ်လာပါက More info ကိုနှိပ်ပါ။

4
Run anyway

Run anyway ကိုနှိပ်ပြီး installer ကို ဆက်ဖွင့်ပါ။

5
Allow Installation

Windows က ခွင့်ပြုချက်တောင်းလာပါက Yes ကိုနှိပ်ပါ။

6
Select Myanglish

တပ်ဆင်ပြီးပါက Win + Space ကိုနှိပ်ပြီး Myanglish ကိုရွေးပါ။ ပြီးရင် Myanglish နဲ့ ချက်ချင်း စတင်ရိုက်နိုင်ပါပြီ။

Features

Myanglish Features

01
Myanglish Typing

English keyboard ကိုအသုံးပြုပြီး Myanglish လို ရိုက်ကာ Space နှိပ်ရုံဖြင့် မြန်မာစကားလုံးအဖြစ် ပြောင်းနိုင်ပါတယ်။

Keyboard layout အသစ်ကို အလွတ်ကျက်စရာမလိုဘဲ ရင်းနှီးပြီးသား Myanglish ပုံစံနဲ့ မြန်မာစာကို လွယ်ကူစွာ ရိုက်နိုင်ပါတယ်။

02
Fast Typing with Auto-Commit

Space နှိပ်ပြီး လိုချင်တဲ့ မြန်မာစကားလုံးကို ရွေးထားပြီးနောက် နောက်စကားလုံးကို စရိုက်တာနဲ့ ရွေးထားတဲ့စကားလုံးကို အလိုအလျောက် အတည်ပြုပေးပါတယ်။

ဒါကြောင့် Space နဲ့ candidate ရွေးရင်း ဆက်တိုက် မြန်မြန်စာရိုက်နိုင်ပါတယ်။ Enter နှိပ်ပြီး အတည်ပြုထည့်ချင်လည်း ရပါတယ်။

03
Learns Your Word Choices

စကားလုံးတွေထဲက user အသုံးများတဲ့ စကားလုံးတွေကို မှတ်သားထားပြီး အသုံးများလာတဲ့ စကားလုံးကို အပေါ်ရောက်လာအောင် ပြောင်းပေးပါတယ်။

ဒါကြောင့် ကိုယ်မကြာခဏသုံးတဲ့ စကားလုံးတွေကို နောက်တစ်ကြိမ်ရိုက်တဲ့အခါ ပိုလွယ်ကူစွာ ရွေးချယ်နိုင်ပါတယ်။

04
Easy Myanmar Stacking

ပတ်ဆင့်စာလုံး ရိုက်ချင်တဲ့အခါ မူရင်းအသံထွက်အတိုင်း ရိုက်ပြီး Ctrl + Enter နှိပ်ရုံဖြင့် ပတ်ဆင့်အဖြစ် ပြောင်းပေးပါတယ်။

လိမ် + မော် + Ctrl + Enter → လိမ္မော်
မင်း + ဂ + Ctrl + Enter → မင်္ဂ
05
English as the Second Candidate

ရွေးချယ်စရာစကားလုံးများရဲ့ ဒုတိယ candidate နေရာမှာ မူရင်း English/Myanglish word ကို အမြဲထားပေးပါတယ်။

မြန်မာစာရိုက်နေရင်း English word သို့မဟုတ် English sentence ရေးချင်တဲ့အခါ မူရင်း English candidate ကို Space နဲ့ရွေးပြီး ဆက်ရိုက်နိုင်ပါတယ်။

06
Smart Spacing for Burmese + English

မြန်မာစာရိုက်နေရင်း English စကားလုံးကို ကြားညှပ်ရိုက်တဲ့အခါ မြန်မာစကားလုံးနဲ့ English စကားလုံးကြားမှာ လိုအပ်တဲ့ space ကို အလိုအလျောက် ထည့်ပေးပါတယ်။

ဒါကြောင့် မြန်မာနဲ့ English ရောပြီးရေးတဲ့ စာတွေကို ဖတ်ရလွယ်ကူပြီး သပ်ရပ်စေပါတယ်။

07
Capital English with CapsLock

မြန်မာစာရိုက်နေရင်း English စကားလုံးအကြီး ရိုက်ချင်တဲ့အခါ CapsLock ကိုအသုံးပြုပြီး English capital letters ရိုက်နိုင်ပါတယ်။

မြန်မာစာရိုက်နေရာကနေ English စာလုံးအကြီးလိုအပ်တဲ့အခါ keyboard layout ကို သီးသန့်ပြောင်းစရာမလိုပါဘူး။

08
Quick Language Switching

Shift + Space ကိုနှိပ်ပြီး Myanglish mode ကနေ English mode ကို အလွယ်တကူ ပြောင်းနိုင်ပါတယ်။

English ရိုက်ပြီးတဲ့အခါ Shift + Space ကို ထပ်နှိပ်ပြီး Myanglish mode ကို ပြန်ပြောင်းနိုင်ပါတယ်။

09
Myanmar Punctuation from English Layout

English keyboard layout ကနေပဲ မြန်မာ punctuation နဲ့ အသုံးများတဲ့ မြန်မာစာလုံးတွေကို တိုက်ရိုက်ရိုက်နိုင်ပါတယ်။

, → ၊
. → ။
: → း
; → ့
\ → င်္
| → င

ဒါကြောင့် punctuation ရိုက်ဖို့အတွက် keyboard layout သီးသန့်ပြောင်းစရာမလိုပါဘူး။

10
Add Your Own Words

မူရင်း Myanglish dictionary ထဲမှာ မရှိသေးတဲ့ စကားလုံးတွေကို candidate popup အောက်မှာရှိတဲ့ + Add / manage words... ကိုနှိပ်ပြီး ကိုယ်လိုချင်တဲ့ စကားလုံးကို ထည့်နိုင်ပါတယ်။

ဒါကြောင့် ကိုယ်အသုံးများတဲ့ နာမည်၊ အသုံးအနှုန်းနဲ့ dictionary ထဲမှာ မပါသေးတဲ့ စကားလုံးတွေကို ကိုယ်တိုင်ထည့်သွင်းအသုံးပြုနိုင်ပါတယ်။

11
Tab for a Real Space

မြန်မာစကားလုံးရိုက်ပြီးနောက် space တစ်နေရာခြားချင်တဲ့အခါ Tab key ကို အသုံးပြုနိုင်ပါတယ်။

Candidate ရွေးချယ်ဖို့သုံးတဲ့ Space နဲ့ စာကြားတကယ့် space ထည့်ဖို့သုံးတဲ့ Tab ကို ခွဲထားတဲ့အတွက် Myanglish ကို မြန်မြန်ဆန်ဆန် ရိုက်နိုင်ပါတယ်။

12
Myanmar Numbers

English keyboard ရဲ့ 0–9 ကို အသုံးပြုပြီး မြန်မာဂဏန်း ၀–၉ ကို တိုက်ရိုက်ရိုက်နိုင်ပါတယ်။

0 → ၀　1 → ၁　2 → ၂　3 → ၃　4 → ၄
5 → ၅　6 → ၆　7 → ၇　8 → ၈　9 → ၉

ABOUT MYANGLISH

Myanglish အကြောင်း

မြန်မာစာရိုက်ဖို့ လက်ကွက်ကျက်စရာ မလိုတော့ဘူး။

Myanglish သည် မြန်မာစာကို ပိုမိုလွယ်ကူ၊ မြန်ဆန်ပြီး သဘာဝကျကျ ရိုက်နိုင်စေရန် ဖန်တီးထားသော Windows မြန်မာစာရိုက်စနစ် (IME) တစ်ခုဖြစ်ပါသည်။

ဤ Project ကို စတင်ခဲ့ရသည့် ရည်ရွယ်ချက်မှာ ရိုးရှင်းပါသည်။ မြန်မာ Keyboard လက်ကွက်ကို သီးသန့်ကျက်မှတ်ရန် မလိုဘဲ မိမိရင်းနှီးပြီးသား English အက္ခရာများဖြင့် အသံထွက်အတိုင်း ရိုက်နှိပ်ကာ မြန်မာစာအဖြစ် ပြောင်းလဲနိုင်စေရန် ဖြစ်ပါသည်။

အစပိုင်းတွင် ရိုးရှင်းသော စာသားပြောင်းလဲသည့် Program တစ်ခုအဖြစ် စတင်ခဲ့သော်လည်း အကြိမ်ကြိမ် စမ်းသပ်ခြင်း၊ အမှားများကို ရှာဖွေပြင်ဆင်ခြင်းနှင့် လက်တွေ့အသုံးပြုမှုများမှတစ်ဆင့် Windows Application အမျိုးမျိုးတွင် အသုံးပြုနိုင်သော IME တစ်ခုအဖြစ် တဖြည်းဖြည်း တိုးတက်လာခဲ့ပါသည်။

ဖန်တီးမှုလမ်းကြောင်းတစ်လျှောက် Windows Application များနှင့် ကိုက်ညီမှု၊ မြန်မာ Unicode စနစ်၊ စာရိုက်သည့်နေရာ မှန်ကန်မှု၊ စကားလုံးရွေးချယ်မှုနှင့် ရှုပ်ထွေးသော မြန်မာဆင့်စာလုံးများကဲ့သို့ နည်းပညာဆိုင်ရာ အခက်အခဲများစွာကို ရင်ဆိုင်ခဲ့ရပါသည်။

အခက်အခဲတစ်ခုချင်းစီကို စမ်းသပ်၊ လေ့လာ၊ ပြန်လည်ပြင်ဆင်ရင်း Myanglish ကို ပိုမိုကောင်းမွန်အောင် ဆက်လက်တည်ဆောက်ခဲ့ပါသည်။

Myanglish သည် ကျွန်တော့်အတွက် Software Project တစ်ခုထက် ပိုပါသည်။

၎င်းသည် စိတ်ကူးတစ်ခုကို လက်တွေ့အကောင်အထည်ဖော်ခြင်း၊ ပြဿနာများကို ကိုယ်တိုင်ဖြေရှင်းခြင်း၊ အမှားများမှ သင်ယူခြင်းနှင့် အခက်အခဲများကြားမှ လက်မလျှော့ဘဲ ဆက်လက်ကြိုးစားခဲ့ခြင်းတို့၏ ရလဒ်တစ်ခုဖြစ်ပါသည်။

ကျွန်တော့်၏ ရည်မှန်းချက်မှာ ရိုးရှင်းပါသည်။

“လူတိုင်း မြန်မာစာကို လွယ်ကူပြီး သဘာဝကျကျ ရိုက်နိုင်စေရန်။”

My Story

စိတ်ကူးတစ်ခုမှ Myanglish IME ဖြစ်လာသည်အထိ

မြန်မာစာရိုက်ဖို့ လက်ကွက်ကျက်စရာ မလိုတော့ဘူး။

Myanglish IME ကို ဖန်တီးဖို့ စတင်စဉ်းစားခဲ့တဲ့အချိန်မှာ ကျွန်တော့်မှာ ရိုးရှင်းတဲ့ ရည်ရွယ်ချက်တစ်ခုပဲ ရှိခဲ့ပါတယ်။ မြန်မာစာကို လူတိုင်း ပိုမိုလွယ်ကူစွာ ရိုက်နိုင်စေချင်တာပါ။

မြန်မာ Keyboard ကို အသုံးပြုတဲ့အခါ စာလုံးတွေရဲ့ တည်နေရာကို မှတ်သားရတာ၊ သီးသန့်လက်ကွက်လေ့လာရတာနဲ့ ဆင့်စာလုံးတွေကို ရိုက်ဖို့ Key အများကြီး မှတ်ထားရတာတွေ ရှိပါတယ်။ ဒါကြောင့် English Keyboard တစ်ခုတည်းကို အသုံးပြုပြီး မြန်မာစကားသံထွက်အတိုင်း ရိုက်လိုက်ရင် မြန်မာစာအဖြစ် ပြောင်းပေးနိုင်တဲ့ စနစ်တစ်ခု ဖန်တီးဖို့ စဉ်းစားခဲ့ပါတယ်။

အစပြုခြင်း

အစပိုင်းမှာ Myanglish ဟာ English အက္ခရာတွေကို မြန်မာစာအဖြစ် ပြောင်းပေးတဲ့ ရိုးရှင်းတဲ့ Converter တစ်ခုသာ ဖြစ်ခဲ့ပါတယ်။ ဒါပေမယ့် ကျွန်တော်လိုချင်တာက စာသားပြောင်းပေးတဲ့ Program တစ်ခုတည်း မဟုတ်ပါဘူး။

Chrome, LINE, Notepad, Microsoft Word နဲ့ တခြား Windows Application တွေမှာ ပုံမှန် Keyboard တစ်ခုလို အသုံးပြုနိုင်တဲ့ IME တစ်ခု ဖြစ်စေချင်ခဲ့ပါတယ်။ ဒီရည်မှန်းချက်ကြောင့် C++, Windows Text Services Framework (TSF), Unicode, CMake, Visual Studio နဲ့ PowerShell စတဲ့ နည်းပညာတွေကို လေ့လာပြီး လက်တွေ့အသုံးချခဲ့ပါတယ်။

ကိုယ်တိုင် ဒီဇိုင်းလုပ်ခဲ့တဲ့ စာရိုက်စနစ်

Myanglish ကို အသုံးပြုရလွယ်ကူစေဖို့ Keyboard ရဲ့ လုပ်ဆောင်ပုံကို ကိုယ်တိုင် သတ်မှတ်ခဲ့ပါတယ်။ စာရိုက်နေချိန်မှာ English အက္ခရာတွေကို အရင်မြင်ရမယ်။ Space တစ်ချက်နှိပ်မှ မြန်မာစာအဖြစ် ပြောင်းမယ်။ နောက်ထပ် Space နှိပ်ရင် တခြားဖြစ်နိုင်တဲ့ စကားလုံးတွေကို ရွေးချယ်နိုင်မယ်။

Enter နှိပ်ရင် စကားလုံးကို အတည်ပြုမယ်။ နောက်စာလုံး စရိုက်လိုက်ရင် အရင်ရွေးထားတဲ့ စကားလုံးကို အလိုအလျောက် အတည်ပြုမယ်။ မှားသွားရင် Backspace နဲ့ မူရင်း Myanglish ကို ပြန်ယူနိုင်ဖို့၊ Esc နဲ့ Conversion ကို ပယ်ဖျက်နိုင်ဖို့လည်း စဉ်းစားခဲ့ပါတယ်။ ဒီလို အသေးစိတ်အချက်တွေကို တစ်ခုချင်း သတ်မှတ်ရင်း Keyboard တစ်ခုရဲ့ User Experience ဟာ ဘယ်လောက်အရေးကြီးလဲဆိုတာ နားလည်လာခဲ့ပါတယ်။

အခက်အခဲတွေ စတင်လာတဲ့အချိန်

Myanglish ကို တကယ့် Windows IME အဖြစ် တည်ဆောက်တဲ့အခါ မမျှော်လင့်ထားတဲ့ ပြဿနာတွေ အများကြီး ကြုံတွေ့ခဲ့ရပါတယ်။ Chrome မှာ အလုပ်လုပ်ပေမယ့် LINE မှာ စာရိုက်ရင်း ရပ်သွားတာ၊ Notepad မှာ Cursor နေရာမှားတာ၊ Application ပြောင်းပြီးနောက် Candidate Window ကျန်နေခဲ့တာတွေ ဖြစ်ခဲ့ပါတယ်။

တစ်ခါတလေ Screen ပေါ်မှာ မြန်မာစာ မှန်မှန်ပြနေပေမယ့် Enter နှိပ်ပြီး အတည်ပြုလိုက်တဲ့အခါ စာလုံးပျောက်သွားတာ၊ ထပ်သွားတာမျိုးတွေ ရှိခဲ့ပါတယ်။ Code တစ်နေရာကို ပြင်လိုက်ရင် တခြားနေရာမှာ ပြဿနာအသစ် ထပ်ပေါ်လာတတ်ပါတယ်။ တစ်ခါတလေ Version အသစ်က အရင် Version ထက်တောင် ပိုဆိုးသွားခဲ့ပါတယ်။

ဒါပေမယ့် Project ကို အစကနေ ပြန်မစခဲ့ပါဘူး။ Error Log တွေကို ဖတ်တယ်။ ပြဿနာဖြစ်တဲ့အကြောင်းရင်းကို ရှာတယ်။ Test Case အသစ်တွေ ဖန်တီးတယ်။ မအောင်မြင်ရင် အရင်အလုပ်လုပ်ခဲ့တဲ့ Version ကို ပြန်ယူပြီး နောက်တစ်နည်းနဲ့ စမ်းသပ်ခဲ့ပါတယ်။

မြန်မာစာရဲ့ ရှုပ်ထွေးမှုကို နားလည်လာခြင်း

Myanglish ကို ဖန်တီးရင်း အခက်ခဲဆုံးအပိုင်းတွေထဲက တစ်ခုက မြန်မာ Unicode နဲ့ ဆင့်စာလုံးတွေ ဖြစ်ပါတယ်။

ဒီလို စကားလုံးတွေကို မှန်ကန်စွာ ရိုက်နိုင်ဖို့ အကြိမ်ကြိမ် စမ်းသပ်ခဲ့ရပါတယ်။ မြန်မာစာမှာ Screen ပေါ်က မြင်ရတဲ့ စာလုံးပုံစံနဲ့ Computer ထဲမှာ သိမ်းဆည်းထားတဲ့ Unicode အစီအစဉ်ဟာ မတူညီနိုင်ပါဘူး။ ဒါကြောင့် စာလုံးတစ်လုံး မှန်မှန်ပေါ်လာရုံနဲ့ မလုံလောက်ဘဲ အတည်ပြုပြီးနောက် Unicode စာသားအဖြစ် မှန်ကန်နေဖို့လည်း လိုအပ်ပါတယ်။

အမှားတွေကနေ သင်ယူခဲ့ခြင်း

Development လုပ်နေစဉ်မှာ Build Error, Registration Error, Encoding Error နဲ့ Windows Security ဆိုင်ရာ အခက်အခဲတွေကိုလည်း ကြုံတွေ့ခဲ့ရပါတယ်။ တစ်ခါတလေ Code Compile မဖြစ်ခဲ့ပါဘူး။ တစ်ခါတလေ DLL ကို Windows က Load မလုပ်နိုင်ခဲ့ပါဘူး။ တစ်ခါတလေ PowerShell Script တွေမှာ Error ဖြစ်ခဲ့ပါတယ်။

အဲဒီပြဿနာတွေကို ဖြေရှင်းရင်း Software Development ဆိုတာ Code ရေးတတ်ရုံနဲ့ မပြီးဘူးဆိုတာ သိလာခဲ့ပါတယ်။ ပြဿနာကို ခွဲခြမ်းစိတ်ဖြာတတ်ဖို့၊ မှားနေတဲ့အကြောင်းရင်းကို ရှာတတ်ဖို့၊ စမ်းသပ်မှုတွေကို စနစ်တကျ လုပ်တတ်ဖို့နဲ့ အရင် Version တွေကို လုံခြုံစွာ သိမ်းဆည်းထားတတ်ဖို့လည်း လိုအပ်ပါတယ်။

Bug တစ်ခုကို ပြင်နိုင်တာထက် ဘာကြောင့် အဲဒီ Bug ဖြစ်ခဲ့လဲဆိုတာ နားလည်နိုင်ခြင်းက ပိုအရေးကြီးတယ်ဆိုတာပါ။

ကျွန်တော် Myanglish ကို ရိုးရိုး စာသားပြောင်းပေးတဲ့ Keyboard တစ်ခုအဖြစ်ပဲ ရပ်တန့်မထားချင်ပါဘူး။ အသုံးပြုသူရဲ့ စာရိုက်ပုံကို ပိုမိုနားလည်နိုင်တဲ့၊ စကားလုံးတွေကို ပိုမိုတိကျစွာ အကြံပြုနိုင်တဲ့၊ စာလုံးပေါင်းအမှားတွေကို ပြင်ဆင်ဖို့ အကြံပြုပေးနိုင်တဲ့ ပိုမိုအသိဉာဏ်ရှိသော မြန်မာစာရိုက်စနစ်တစ်ခု ဖြစ်လာစေချင်ပါတယ်။

အနာဂတ်မှာ Myanglish ကို လူတိုင်း လွယ်ကူစွာ Install လုပ်နိုင်ပြီး နေ့စဉ်အသုံးပြုရာမှာ ယုံကြည်စိတ်ချရတဲ့ Software တစ်ခု ဖြစ်လာစေဖို့ ဆက်လက်ကြိုးစားသွားမှာပါ။
