Installation Guide

Myanglish Install ပြုလုပ်နည်း

01Download

အပေါ်က Download Full Version သို့မဟုတ် Download Lite Version ကို ရွေးပါ။ Lite Test Artifact က ZIP ဖြစ်ပြီး Extract All လုပ်ပြီးမှ Installer ကို ဖွင့်ရပါမယ်။

02Run Installer

Full Version

Run MyanglishInstaller.exe

Download လုပ်ထားတဲ့ MyanglishInstaller.exe ကို double-click လုပ်ပါ။ Right-click → Run as administrator မလုပ်ပါနှင့်။

Lite Version

Run MyanglishInstaller-Lite.exe

Windows Smart App Control / SmartScreen Warning ကြုံနေရသူများ စမ်းသပ်နိုင်တဲ့ Version ဖြစ်ပါတယ်။ ZIP ကို Extract လုပ်ပြီး MyanglishInstaller-Lite.exe ကို double-click လုပ်ပါ။ Right-click → Run as administrator မလုပ်ပါနှင့်။

03Allow Installation

Windows User Account Control (UAC) က ခွင့်ပြုချက်တောင်းလာပါက Download Source နဲ့ File Name ကို သေချာစစ်ဆေးပြီး ယုံကြည်စိတ်ချရမှ Yes ကိုနှိပ်ပါ။ Unknown publisher ဟု ပေါ်နိုင်ပါတယ်။

Windows Smart App Control က File ကို Block လုပ်ပါက အဲဒီ Warning ဟာ UAC နဲ့ မတူပါ။ Security Protection ကို ပိတ်ပြီး မကျော်ပါနှင့်။

04Select Myanglish

Installation အောင်မြင်ပြီးရင် Win + Space ကို နှိပ်ပြီး Myanglish ကို ရွေးပါ။ Notepad မှာ မြန်မာစာ ရိုက်ကြည့်ပါ။
